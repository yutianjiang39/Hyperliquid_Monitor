# 量化指标

[← 返回 README](../README.md)

- **收益**：
  - 累计盈亏、TWR（Modified Dietz 串联）、年化、XIRR（资金加权）、投入资本回报；
  - 最佳/最差日、周、月，月度收益日历；
  - 7 天 / 30 天 / 90 天 / 年初至今 / 全部窗口切换。
- **风险**：
  - 最大回撤（百分比与金额）、回撤段、水下曲线；
  - Sharpe、Sortino、Calmar、**Omega**、**尾部比率**（日收益 95 分位 ÷ |5 分位|）、VaR/CVaR 95%；
  - 回撤时长（峰→谷）、恢复时长（谷→新高）、最长水下、回撤次数（≥5%）与平均深度、水下 / 创新高时间占比、恢复因子、盈利峰值、初始亏损；
  - 月度胜率与月收益标准差；杠杆调整 ROI（TWR ÷ 平均日末杠杆，日内交易者不适用时留空）；
  - Ulcer、偏度、峰度、30 日滚动指标放在风险页“更多统计”折叠区；
  - 按盯市敞口计算的杠杆序列。
- **交易行为**：
  - 回合胜率、盈亏比、Profit factor、期望值、连胜连败、平均 / 中位持仓时长；
  - 盈亏效率比（净盈亏 ÷ (总盈利 + |总亏损|)）、**盈利集中度**（前 10% 回合占总盈利、最大单笔占比）；
  - 分币种盈亏（已实现、手续费、资金费、净额、胜率、多空），分多空的胜率与盈亏；
  - 资金费占盈亏比、Maker 占比、换手倍数（成交量 ÷ 当前 / 平均净值）、单位成交额收益（bps）；
  - 持仓时长分布，多空拆分，盈亏 × 持仓时长散点；
  - 小时 × 星期热力图，Maker / TWAP / HIP-3 / 现货占比，强平次数（只计本钱包被强平的成交）。
- **成本**：手续费（bps）、资金费收付（按币种）、Builder 费、成本占毛利比例、费率档与折扣。
- **持仓与资产**：当前持仓、各账户桶价值、现货余额、子账户、金库、质押、挂单。
- **画像**：频率、风格、方向、集中度、杠杆等标签，附判定规则。

## 第三轮：口径修正与新增指标

在 v3.1 基础上的一轮口径修正和指标补充（配置版本号仍为 3.1.0）：

- **计算修正**：
  - 回撤把窗口起点计入峰值；没有可用数据的 TWR、月度收益保持为空，不显示成 0；
  - 资金费按每笔支付拆分收入与支出；手续费卡片和图表统一用 USD；
  - 成交笔数与反手按唯一记录计数；活跃日占比按日历日计算；
  - 截止时刻落在两次官方采样之间时插值；只有一个不完整交易日时按比例缩放；
  - 手续费拖累改为除以盈利回合的真实毛利；
  - Dune 插件改为带参数执行已保存查询，并核对返回的钱包地址。
- **新增指标**：
  - 峰值资本回报（ROPC）、盈亏平衡胜率、胜率的 Wilson 置信区间、有效独立回合数；
  - 按历史平均亏损归一化的 R 统计（期望、最差回合、超过 −3R 的回合数）；
  - 最近 20 回合条带、盈利 / 亏损前五笔、去掉最佳一笔或五笔后的净盈亏、资金概览；
  - BTC Beta 与扣除 BTC 影响后的超额收益（HAC 标准误）；
  - 当前持仓的 5% / 10% / 20% 价格冲击压力测试；
  - 订单数、每活跃日订单数、强平事件数。
- **证据强度**：与数据完整性分开评级。活跃日 ≥ 90、回合 ≥ 100、活跃月 ≥ 6 为最高档；≥ 30 / 20 / 2 为中档；否则为最低档。报告同时给出距离下一档还差多少。
- **对账**：区间与官方采样点对齐；可比采样不足两个时标为 `insufficient_overlap`；没有发现缺口时历史状态标为 `no_gap_detected`，不写成“完整”。
- **报告**：内置 Inter 与 JetBrains Mono 字体；总览、成本、持仓、数据质量页展示以上新字段。
